사용법

Tab 하위 노드 추가
Enter 형제 노드 추가
Space F2 더블클릭 텍스트 편집 (그냥 타이핑해도 편집 시작)
Shift+Enter 편집 중 줄바꿈
Esc 편집 취소
Delete 노드 삭제 (하위 포함)
방향키 노드 이동
Alt+↑/↓ 순서 바꾸기
/ 접기 / 펼치기
Ctrl+Z / Y 실행 취소 / 다시 실행
노드 드래그 다른 노드 위에 놓으면 그 아래로 이동
배경 드래그 / 휠 화면 이동 / 확대·축소

모든 변경은 이 브라우저(localStorage)에 자동 저장됩니다. 다른 기기로 옮기거나 백업하려면 JSON으로 저장하세요.
