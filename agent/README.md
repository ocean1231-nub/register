# 파일 작업 에이전트

터미널에서 대화하면서 내 컴퓨터의 파일을 읽고, 찾고, 고치고, 명령을 실행하는 Claude 기반 에이전트입니다.
파일 변경과 명령 실행은 매번 미리보기를 보여주고 승인을 받습니다. 거부할 때 이유를 적으면 에이전트가 그 피드백을 반영해 다시 시도합니다.

## 준비물

- Python 3.10 이상
- Anthropic API 키: https://platform.claude.com/settings/keys 에서 발급 (사용한 만큼 요금이 청구됩니다)

## 실행

Linux / macOS / 크롬북(Linux):

```
./run.sh 작업할폴더
```

Windows:

```
run.bat 작업할폴더
```

처음 실행하면 필요한 패키지를 자동으로 설치하고 API 키를 묻습니다. 키를 이 컴퓨터에 저장하면(`~/.config/claude-file-agent/config.json`) 다음부터는 묻지 않습니다. 환경변수 `ANTHROPIC_API_KEY`가 있으면 그것을 씁니다.

크롬북(Debian)에서 `venv 생성 실패`가 나오면 먼저 `sudo apt install python3-venv`를 실행하세요.

## 옵션

| 옵션 | 설명 |
| --- | --- |
| `--model claude-opus-5-5` | 기본값. 가장 정확 |
| `--model claude-sonnet-5-5` | 약 절반 가격 |
| `--model claude-haiku-4-5` | 가장 저렴, 단순 작업용 |
| `--effort low/medium/high/xhigh/max` | 생각 깊이. 기본 `medium`. 높을수록 정확하지만 비쌈 |

## 대화 중 명령

- `/cost` 지금까지의 토큰 사용량과 예상 비용
- `/clear` 대화 기록 지우기
- `/exit` 종료
- 작업 중 `Ctrl+C` 현재 작업 중단

## 에이전트가 할 수 있는 일

| 도구 | 승인 필요 |
| --- | --- |
| 파일 목록 보기, 파일 읽기, 내용 검색 | 아니오 |
| 파일 쓰기, 부분 수정, 이동/이름 변경 | 예 (변경 내용 미리보기) |
| 삭제 | 예 (`.agent-trash/` 폴더로 옮겨서 복구 가능) |
| 셸 명령 실행 | 예 |

승인 화면에서 `a`를 누르면 이번 실행 동안 같은 종류의 작업을 다시 묻지 않습니다.

## 안전 장치와 한계

- 파일 도구는 실행할 때 지정한 작업 폴더 밖에 접근할 수 없습니다.
- 셸 명령은 승인 후 그대로 실행되므로 작업 폴더 밖에도 영향을 줄 수 있습니다. 명령 내용을 확인하고 승인하세요.
- 텍스트 파일만 읽습니다. PDF, Word, 이미지는 읽지 못합니다.
- 대화 기록은 프로그램을 끄면 사라집니다.
- 화면에 표시되는 비용은 토큰 수로 계산한 추정치입니다. 정확한 청구액은 https://platform.claude.com 에서 확인하세요.
